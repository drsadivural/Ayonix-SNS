# Design assets

Authoritative screen content: the 13 numbered-by-order screens in screens.json, generated by scripts/build_design.py; exact commercial configuration is contracts/pricing.json. These are designed mockup images, not screenshots of a functioning application. All statistics/account names/statuses are example design data. No provider IDs are fabricated.

Open index.html for the screen gallery and local Custom-plan price calculator. Open design-overview.pdf to review/print all screens. The source can be regenerated with Python/reportlab and Poppler; the delivered PNG/PDF files do not require those dependencies to view.

Generated concept-board-core.png and concept-board-flows.png provide visual inspiration. Image generation introduced nonauthoritative details such as yearly billing, a Pro label, extra mobile navigation and feature text. **Do not implement those deviations.** The product has monthly billing only, the specified plan names, exactly five menus and the feature mapping in pricing.json. The deterministic PNGs and written contract supersede all generated text/details.

all-screens.png is a contact sheet for review. Mobile screenshot is a dedicated narrow-layout concept displayed on a larger presentation canvas; application responsive behavior still requires real browser verification at 390×844.
